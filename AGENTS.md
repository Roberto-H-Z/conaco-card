# Instrucciones de skills del proyecto

## UI/UX Pro Max

No activar ni aplicar la skill `ui-ux-pro-max` ni las skills complementarias que el instalador agregue automáticamente en `.agents/skills` (por ejemplo, `ui-styling`, `design-system` o `brand`), aunque la tarea sea de interfaz o diseño.

Úsala solamente cuando el usuario la solicite de forma explícita, por ejemplo: `usa ui-ux-pro-max`, `aplica la skill de UI/UX` o una instrucción inequívoca equivalente.
